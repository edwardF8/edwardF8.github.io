Overview

Machine learning for powder X-ray diffraction (PXRD) symmetry classification is being trained at scale, yet the field has no common evaluation standard: papers report results on different subsets of experimental archives, with different target taxonomies, preprocessing steps, and metrics. InformedXRD is evaluation infrastructure, not a new architecture, meant to make PXRD-ML claims more comparable, physically meaningful, and auditable.

Issues

The field has no shared way to grade these models.

Wrong target

Powder diffraction alone cannot tell apart space groups that share the same missing peaks.

Non-reproducible benchmarks

Each paper scoops its own subset of RRUFF, so scores cannot be compared.

Flat metrics

A neighbor in symmetry and an unrelated group get the same penalty: both are just “wrong”.

Missing baselines

A model can score by guessing the most common labels. Without a guess-only baseline, nobody can tell.

Contributions

1

Extinction-group mapping (230 → 99)

A verified, machine-readable table from the 230 space groups to the 99 extinction groups, the finest classes powder diffraction can identify from systematic absences alone.

2

Benchmarks specified as code

A construction method whose inclusion rules reproduce from a frozen snapshot, instantiated as RRUFF-473, RRUFF-325, and opXRD-98.

3

An evaluation protocol

Four tools to report alongside Top-k accuracy.

Prior-only baselines

Ignores the pattern and stamps the same Top-5 list on every scan: deployable (training frequencies) or oracle (the test set’s own frequencies).

Label-permutation test

Hold the model’s guesses fixed and shuffle the labels 10,000 times. If the score does not drop, the model is not reading the pattern.

Symmetry-graph error metric

Hops between the guess and the truth on the condensed translationengleiche subgroup graph, with exact null references.

Stratified reporting

Report accuracy per fit-quality stratum, next to how many extinction groups each stratum spans.

Demonstrations

On four ViT checkpoints, a 1D residual CNN, and six XRDBench architectures, these choices change model rankings and expose confounds that aggregate accuracy hides.
